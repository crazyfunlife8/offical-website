## 對 active 設計的接管原則

當未來升級任一 teaser 為正式內容時：

1. **先讀本頁該頁段落** → 取得設計概念 + WOW 時刻 + 敘事意圖
2. **對照 active 紅線**（CLAUDE.md §一 三條設計判斷 + §二 禁止範圍）
3. **剝離已被推翻的具體 spec**（字型 Exo 2 / IBM Plex Mono、3D 太空人、磁性按鈕、座標文字、God Rays 等等已退役元素）
4. **用當前 active 設計語言重新落地**（俐落 / 線條 / 電影感 / 反差 / Liquid Glass / Chiron Sung / Italiana / Fraunces 字型系統）
5. **若敘事 anchor 與當前紀律衝突**：以紀律為準、敘事 anchor 退讓（但記錄衝突原因到 commit body 或 CLAUDE.md 偏差表）
