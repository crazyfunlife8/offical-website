## 1. 字型系統（Q2 決議：B 半替換）

### 1.1 字型分派

| 變數 | 字型 | 載入 | 用途 | 不得用於 |
|------|------|------|------|----------|
| `--f-sans` | Noto Sans TC | Google Fonts | 全站中文內文、多數 UI 文字 | — |
| `--f-serif` 🆕 | **Fraunces Variable**（opsz 9–144, wght 100–900, SOFT 0–100） | Google Fonts | 英文大標、英文副標、英文引言、數字展示 | 中文、內文、按鈕文字 |
| `--f-mono` | JetBrains Mono | Google Fonts | 座標文字、技術細節、數據 | 段落內文 |
| `--f-bebas` | Bebas Neue | Google Fonts | Hero「UNCONVENTIONAL」單一次使用 | 其他頁任何地方 |
| ~~`--f-disp`（Exo 2）~~ | — | — | **廢止** | — |

### 1.2 Fraunces Variable 的使用紀律（關鍵）

Fraunces 的 `opsz`（光學尺寸）是這套字型的靈魂，也是整個質感訴求的第一張牌。多數官網不用這個功能，只把 Variable 當普通字型載進來，這是浪費。

| 使用情境 | 字級範圍 | `opsz` 值 | `wght` 值 | `SOFT` 值 | 字腔效果 |
|----------|----------|-----------|-----------|-----------|----------|
| Display（英文大標、Hero 宣言） | ≥ 48px | 144 | 300–400 | 0–20 | 字腔收緊、襯線銳利、大字不鬆散 |
| Title（區塊標題） | 28–40px | 72 | 400–500 | 30 | 中等張力，標題感但不戲劇化 |
| Subtitle（英文副標、引言） | 18–24px | 36 | 400 | 50 | 字腔放鬆、襯線柔化 |
| Inline（內文嵌英文字） | 14–18px | 14 | 400 | 50 | 貼近正文節奏，避免視覺噪點 |

**實作方式**：CSS 變數字型軸直接驅動，不用多個字型檔。

```css
.display-en {
    font-family: var(--f-serif);
    font-variation-settings: "opsz" 144, "wght" 300, "SOFT" 10;
    letter-spacing: -0.02em;
}
```

### 1.3 中英混排基線對齊

Noto Sans TC（無襯線）與 Fraunces（襯線）基線不同。混排時以中文基線為準，英文用 `font-feature-settings` 微調。

```css
.mixed-text {
    font-feature-settings: "tnum" 1;  /* 等寬數字避免跳位 */
}
```

## 2. 基線網格（Baseline Grid）

### 2.1 網格單位

**8pt 基線網格 + 4pt 半步網格**。所有垂直距離（行高、margin、padding）必須落在 4pt 倍數上。

```css
:root {
    --grid-base: 8px;
    --grid-half: 4px;
}
```

### 2.2 縱向節奏

所有文字行高取 4pt 倍數，讓段落基線對齊。

| 字級 | 行高 | 倍率 |
|------|------|------|
| 12px（caption） | 16px | 1.333 |
| 14px（small） | 20px | 1.429 |
| 16px（body） | 24px | 1.5 |
| 18px（lead） | 28px | 1.556 |
| 24px（h3） | 32px | 1.333 |
| 32px（h2） | 40px | 1.25 |
| 48px（h1） | 56px | 1.167 |
| 72px（display） | 80px | 1.111 |

### 2.3 落地驗證方式

首頁實作後，開 Chrome DevTools 疊 8pt 格線 screenshot 一次，任何元素底邊偏格 > 1px 就回來改。

## 3. 字級階梯（Modular Scale）

基底 16px，比率 **1.333（Perfect Fourth）**，產生「編輯式」節奏（非科技感的 1.5 大跳）。

| Token | 計算值 | 四捨五入 | 用途 |
|-------|--------|----------|------|
| `--fs-caption` | 16 ÷ 1.333² | **9px** | 座標文字、極細註記（實際最小用 10–12） |
| `--fs-xs` | 16 ÷ 1.333 | **12px** | 標籤、座標 |
| `--fs-sm` | — | **14px** | 次要內文 |
| `--fs-base` | 16 | **16px** | 內文基準 |
| `--fs-md` | 16 × 1.125 | **18px** | Lead 段落 |
| `--fs-lg` | 16 × 1.333 | **21px** | 小標題 |
| `--fs-xl` | 16 × 1.333² | **28px** | H3 |
| `--fs-2xl` | 16 × 1.333³ | **38px** | H2 |
| `--fs-3xl` | 16 × 1.333⁴ | **50px** | H1 |
| `--fs-4xl` | 16 × 1.333⁵ | **67px** | Display |
| `--fs-5xl` | 16 × 1.333⁶ | **90px** | Hero |

**與現有 `tokens.css` 的偏差**：現行是鬆散整數系列（48 / 64 / 88），升級為比率階梯。實作時同步更新。

## 4. 留白節奏（Whitespace Rhythm）

留白不是「空隙」是「節奏切分」。三種節奏，不可混用。

| 節奏 | 間距（以 8pt 基數）| 用途 | 原則 |
|------|---------------------|------|------|
| **緊** | 8 / 16 / 24 | 同一語意群（標題 → 副標 → 描述） | 讓讀者知道「這三個是一組」 |
| **中** | 48 / 64 / 80 | 區塊內分段 | 讓讀者知道「這是同個區塊的下一件事」 |
| **寬** | 120 / 160 / 200 | 區塊之間 | 讓讀者知道「上一件事結束了，深呼吸」 |

**克制原則**：單頁只允許 **一次** 使用超過 200px 的大留白（通常在 Hero 結束進入第一個內容區塊時）。其他地方用超大留白就是炫技，質感反而掉。

## 5. 共用視覺元素庫

10 個元素。每個含四個欄位：**抽象特性 / 技術實作 / 使用原則 / 克制邊界**。落地時必須四項齊備，缺一不得使用。

### 元素 1｜光雕（Emboss / Deboss / Sculpt）

> **這是全站質感的根。其他元素可以換，這個不行。**

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 讓關鍵文字「從深空被光雕刻出來」，不是「貼在背景上」。本質是光源方向一致性 + 極細對比層 |
| 技術實作 | 三層 text-shadow token（`--ts-emboss` / `--ts-deboss` / `--ts-sculpt`）已在 tokens.css 定義。光源統一由「上方 +15°」進入（與 God Rays 同向） |
| 使用原則 | 僅用於：① 每頁 H1 ② 每頁 Hero 宣言 ③ 每頁 CTA 按鈕文字 ④ 服務卡標題（services.html） |
| 克制邊界 | ❌ 內文段落 ❌ 導覽列 ❌ 頁尾 ❌ 兩個光雕元素相鄰（會打架） |

### 元素 2｜描邊進場（SVG Stroke Reveal）

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 邊框不是「畫出來的」是「正在被畫」。本質是時間軸上的造型生成，而非造型本身 |
| 技術實作 | SVG `stroke-dasharray` + `stroke-dashoffset`，IntersectionObserver 觸發，duration 1.2s，ease `cubic-bezier(0.65, 0, 0.35, 1)`。描邊完成後 300ms fade in 內容 |
| 使用原則 | 服務卡、關鍵數據框、時間軸節點、分隔線進場 |
| 克制邊界 | ❌ 迴圈不停重播 ❌ 兩個描邊動畫在同視窗內同時進行 ❌ 短於 0.8s 的快速版本（會失去「正在被畫」的感覺） |

### 元素 3｜金屬掃光（Metal Sweep）

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 光學儀器反射面的偶發反光。本質是「被看見一瞬即收」，不是持續閃爍 |
| 技術實作 | `linear-gradient` 45° 透明 → rgba(232,240,255,0.4) → 透明，`background-position` 從 -200% 到 200%，duration 1.8s，ease-out。觸發後鎖 60 秒 cooldown |
| 使用原則 | **全站僅 2 處**：① Hero「UNCONVENTIONAL」進站後 2 秒一次 ② 最終 CTA 按鈕游標停留 800ms 後一次 |
| 克制邊界 | ❌ Hover 每次都觸發 ❌ 進場動畫連續播 ❌ 用在內文或標題 |

### 元素 4｜星座連線（Constellation Lines）

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 個別獨立的點，被極細線暗示成一個整體。本質是「可見但不強制」的關聯 |
| 技術實作 | SVG `<line>` stroke-width 0.5px，stroke rgba(0,200,255,0.25)，點與點之間以「最近鄰」連線規則。進場時 stroke-dashoffset 動畫 |
| 使用原則 | Bento 六卡（index.html）、服務總覽卡（services.html）、時間軸節點（about.html） |
| 克制邊界 | ❌ 連線粗於 1px（會變成「框」不是「暗示」）❌ 連線飽和度太高（變賽博龐克）❌ 連線 hover 變化（破壞「靜默星圖」感） |

### 元素 5｜體積光 God Rays

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 深空中穿透霧氣的一道光。本質是「光源方向」的宣告，而非光本身 |
| 技術實作 | 頁面左上 +15° 斜射，`linear-gradient(105deg, rgba(23,54,245,0.08) 0%, transparent 40%)`，`mix-blend-mode: screen`。極緩漂移 animation 120s 或完全靜態 |
| 使用原則 | 每頁 Hero 區塊頂部**一次**。方向永遠一致（+15°） |
| 克制邊界 | ❌ 多道交叉 ❌ 動畫時間短於 60s ❌ 用在非 Hero 區塊 ❌ 飽和度高於 0.12 |

### 元素 6｜稜鏡折射光斑（Prism Flare）

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 光穿過稜鏡產生的極緩光譜橫越。本質是「時間的流逝」不是「裝飾的移動」 |
| 技術實作 | 小圓光斑（60–80px），`filter: blur(20px)`，沿水平軸從左到右橫越，duration 24s，`ease-in-out`，**單次不 loop**。顏色以 conic-gradient 做極淡稜鏡彩（飽和度 ≤ 0.15） |
| 使用原則 | **僅 2 處**：① index.html 品牌故事預覽區塊 ② about.html 沿革時間軸 |
| 克制邊界 | ❌ 迴圈播放 ❌ 色彩飽和 ❌ 與金屬掃光同區塊使用 |

### 元素 7｜座標文字（Coordinates）

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 天文觀測站儀器面板的經緯度標記。本質是「每個位置都被精準記錄」的可信感 |
| 技術實作 | `font-family: var(--f-mono)`, `font-size: 10px`, `letter-spacing: 0.15em`, `color: rgba(232,240,255,0.35)`。格式 `LAT 24°57'N / LON 121°13'E / Z -2600` |
| 使用原則 | 每頁四角落（top-left / top-right / bottom-left / bottom-right），`position: fixed` 或 `absolute`。各頁數值可對應主題微調（about 用實際地址座標，services 用 Z 軸深度） |
| 克制邊界 | ❌ 動畫或閃爍 ❌ 飽和度高於 0.4 ❌ 字級大於 12px |

### 元素 8｜磁性按鈕（Magnetic Button）

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 引力感知的暗示。本質是「被吸引而非被推銷」 |
| 技術實作 | 游標距離按鈕中心 < 120px 時，按鈕 `transform: translate(dx*0.15, dy*0.15)`，最大偏移 8px。離開時 `transition: transform 0.6s cubic-bezier(0.22, 1, 0.36, 1)` 回彈 |
| 使用原則 | **全站僅 1 顆**：每頁的主 CTA（index 是最終 CTA，about 是聯絡入口，services 是諮詢按鈕） |
| 克制邊界 | ❌ 同頁多顆磁性按鈕 ❌ 移動距離超過 8px（會感覺不穩）❌ 彈回時間短於 0.5s（會像果凍） |

### 元素 9｜內凹陰影（Inset Shadow）

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 光源從上方進入，材質內部有深度。呼應光雕但作用在容器而非文字 |
| 技術實作 | `--shadow-inset` 與 `--shadow-inset-strong` 已於 tokens.css 定義 |
| 使用原則 | 主 CTA 按鈕、關鍵容器（引言框、數據展示框） |
| 克制邊界 | ❌ 卡片全部都套（失去重點）❌ 與外發光陰影疊加 |

### 元素 10｜基線對齊字塊（Baseline-Locked Type Block）

> 這是前面九個元素的「底板」。它本身不炫，但沒有它，前面九個都會失去質感。

| 欄位 | 內容 |
|------|------|
| 抽象特性 | 所有文字基線對齊 8pt 網格，所有段落頂邊也對齊。本質是「被精密校準的印刷品」 |
| 技術實作 | 所有 `margin-top` / `margin-bottom` 使用 8 的倍數。所有 `line-height` 使用 4 的倍數。中英混排時以中文基線為準 |
| 使用原則 | 全站所有文字區塊 |
| 克制邊界 | ❌ 任何魔術數字（13px、27px 等非網格值）❌ `padding-top` 與 `margin-top` 混用導致基線偏移 |

## 6. 元素組合原則

十個元素不是菜單，不是「每頁都用滿」。組合有三條鐵律。

### 6.1 一頁至多四個元素同時出現

超過四個就是炫技，質感會崩。計算規則：光雕、描邊、座標、基線對齊 **不計入四個名額**（它們是底板）。計入名額的是：金屬掃光、星座連線、God Rays、稜鏡折射、磁性按鈕、內凹陰影。

### 6.2 一頁必有一個「簽名元素」

每頁有個元素是「本頁代表作」，其他元素為它讓位。簽名元素在該頁以最完整形式呈現，其他頁使用時保持克制。

### 6.3 兩個動態元素不同時進行

金屬掃光、稜鏡折射、磁性按鈕、描邊進場——同一時間視窗內只能有一個在動。靜態元素（座標、光雕、內凹陰影）不受此限。

## 8. 克制總則（什麼時候什麼都不做）

這是最容易被忽略但最決定質感的部分。以下五種情境必須「克制」。

| 情境 | 不做什麼 |
|------|---------|
| 內文段落 | 不加任何裝飾元素。純文字 + 基線對齊 + 行高 1.5 |
| 導覽列與頁尾 | 不加光雕、不加動效、不加描邊。保持系統級冷靜 |
| 兩個區塊之間的大留白 | 什麼都不放。留白本身就是元素 |
| 第二次出現的元素 | 降級使用（描邊 1.2s → 0.6s，光雕飽和度減半等） |
| 當頁面已有三個元素 | 不再加第四個，即使看起來「還能放」 |

## 10. 實作校準清單（首頁落地後回校）
