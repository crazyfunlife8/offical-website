## 二、CSS 五層架構

### 載入順序（每頁固定，不得更改順序）

```html
<link rel="stylesheet" href="assets/css/tokens.css">
<link rel="stylesheet" href="assets/css/base.css">
<link rel="stylesheet" href="assets/css/components.css">
<link rel="stylesheet" href="assets/css/animations.css">
<link rel="stylesheet" href="assets/css/pages/[page].css">
```

### tokens.css — 設計變數總表

```css
:root {
    /* ─── Colors ─── */
    --c-blue:   #1736F5;
    --c-navy:   #0b1a7a;
    --c-black:  #050d2e;
    --c-yellow: #FFC709;
    --c-white:  #FFFFFF;
    --c-muted:  rgba(255,255,255,0.55);
    --c-accent: var(--c-yellow);   /* 預設黃色，各頁可 override */

    /* ─── Typography ─── */
    --f-sans: 'Noto Sans TC', sans-serif;
    --f-disp: 'Exo 2', sans-serif;
    --f-mono: 'IBM Plex Mono', monospace;

    /* ─── Spacing ─── */
    --sp-xs: 0.5rem;
    --sp-sm: 1rem;
    --sp-md: 2rem;
    --sp-lg: 4rem;
    --sp-xl: 7rem;

    /* ─── Layout ─── */
    --max-w:      1200px;
    --sec-px:     2.5rem;
    --radius:     8px;
    --radius-pill: 50px;

    /* ─── Transitions ─── */
    --t-fast: 0.2s ease;
    --t-base: 0.3s ease;

    /* ─── Z-index ─── */
    --z-nav:     100;
    --z-overlay: 999;
}
```

### 頁面 accent override 範例

system.html 是全站唯一使用青色強調的頁面。做法：在 `pages/system.css` 最頂部覆寫一個變數，不動任何元件樣式：

```css
/* assets/css/pages/system.css */
:root { --c-accent: #00FFCC; }
```

所有引用 `var(--c-accent)` 的元件（按鈕邊框、hover 狀態、標籤、卡片 glow）自動跟著換色。

## 三、JS 三層架構

### 每頁固定載入腳本（放 `</body>` 前）

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/gsap.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/ScrollTrigger.min.js"></script>
<script src="assets/js/core.js"></script>
<script src="assets/js/nav.js"></script>
<script src="assets/js/pages/[page].js"></script>
```

### 僅 index.html 額外載入

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
<!-- Three.js 必須在 index.js 之前 -->
```

### nav.js — 唯一 nav 來源

nav HTML 以字串形式定義在 nav.js 內，注入每頁 body 最前面。**改導覽列只改這一支，12 頁同步生效。**

```js
// assets/js/nav.js
const NAV_HTML = `
  <nav class="site-nav">...</nav>
  <nav class="dock-nav">...</nav>
`;
document.body.insertAdjacentHTML('afterbegin', NAV_HTML);

// 自動 highlight 目前頁面連結
document.querySelectorAll('.nav-links a, .dock-nav a').forEach(a => {
    if (a.href === location.href) a.classList.add('active');
});
```

### core.js — 全站共用邏輯

- `gsap.registerPlugin(ScrollTrigger)`
- 通用 scroll reveal（偵測 `[data-reveal]` 屬性，統一進場動畫）
- Nav 滾動行為（超過 100px 加深背景）

## 五、響應式斷點策略

| 斷點 | 值 | 觸發內容 |
|------|----|---------|
| `--bp-md` | 900px | 桌面 nav → 底部 Dock；多欄格線 → 單欄 |
| `--bp-lg` | 1200px | 內容區塊最大寬度限制 |

撰寫方式採 **desktop-first**：預設樣式為桌面版，media query 只處理手機降級行為。

## 六、效能邊界規則

| 規則 | 執行方式 |
|------|---------|
| Three.js 僅首頁 | `<script>` 標籤只寫在 index.html，其他頁不引入 |
| 手機不跑 3D | `pages/index.js` 開頭偵測 `window.innerWidth < 900`，直接 return |
| canvas 背景僅 system.html | `pages/system.js` 管理，不外溢 |
| 圖片懶加載 | 摺疊以下所有 `<img>` 加 `loading="lazy"` + 明確 `width` / `height` |
| 字型預連線 | `<link rel="preconnect">` 已寫入標準模板 |

## 七、開發流程規則

| 項目 | 規則 |
|------|------|
| 工作分支 | `redesign` 分支開發，完成後合併 `main` 上線 |
| 現有網站保護 | 改版期間 `main` 維持現有版本，訪客不受影響 |
| 佔位符標記 | 所有待補內容統一加 `data-placeholder="true"`，方便搜尋替換 |
| CSS 命名 | BEM-lite：`component__element--modifier` |
| JS 命名 | 函數 camelCase、檔名 kebab-case |
| 禁止行為 | 禁止在 components.css 寫頁面專屬樣式；禁止在頁面 CSS 重新定義 token 值（只能 override `--c-accent`） |
