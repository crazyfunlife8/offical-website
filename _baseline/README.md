## 為什麼整個資料夾還留著（不刪不重寫）

1. **回查價值**：4 月當時的設計脈絡、決策過程、被棄用框架的推導——想知道「當初為什麼這樣想」可以回查
2. **歷史 baseline**：規格書 v1.0「提案確認中」的 baseline 反映提案當下的視覺願景（觀測儀質感、3D 太空人、6 卡 Bento），是當下決策不能省略的歷史錨點
3. **重寫風險**：active CLAUDE.md 已完整紀錄所有實作偏差、再逐項對齊重寫只會失去 baseline 價值且製造「半新半舊」更亂的狀態

## 本資料夾的工作流定位

### 兩種角色文件

| 角色 | 文件 | 修改規則 |

| **Active 發想參考**（living）| `頁面故事線_精煉版.md` | ✅ 可隨服務定位 / 故事線調整持續更新 |

### 工作流

- ✅ 升級任一 teaser 為正式內容前 → **先讀** `頁面故事線_精煉版.md` 該頁段落 → 取得設計概念 + WOW 時刻 + 敘事 anchor → 用 active 設計語言落地
- ✅ 想知道「4 月提案當下的完整構想 / 推導過程」→ 讀其他 5 份歷史 baseline
- ✅ 想看「為什麼某些設計後來被棄用」→ 對照本資料夾 vs `../CLAUDE.md` 偏差表
- ❌ **不要**把歷史 baseline 5 份當「現役 spec」用（例：規格書 v1.0 寫的「品牌名 NestX」「Exo 2 字型」「3D 太空人」「磁性按鈕」「座標文字」「God Rays」均已棄用）
