## 2. 保護清單（2026-04-19 使用者拍板）

以下三區在任何元素實作過程中**必須完整保留**，不得被元素邏輯覆寫或擠占。

### 保護區 A｜Hero 標題文字內容
- **保護內容**：Hero 五行標題的**文字字元本身**
- **可動部分**：字型、字重、字級、間距、行距、顏色、動態、軸動、位置、排版結構
- **應用規則**：元素 1 Variable Font 軸動、元素 2 格線破格、元素 7 潮汐進場等可作用於此區塊，但產出的 HTML 文字節點內容必須與現有 index.html 相同

### 保護區 B｜主視覺背景
- **保護內容**：
  - Three.js 黑洞漩渦粒子系統（`initStarfield()` 整個函式）
  - 所有粒子參數：COUNT=6500、R_MIN=0.42、SPIRAL_K=0.42、TILT=π/12、橢圓比 b/a=0.38、ROT_BY_TYPE 四色差速、BASE_PULL=0.000010、暖機 6000 幀
  - 三層粒子結構（主軌道 6500 + 星際塵埃 2800 + 背景星塵 1800）
  - B 本質亮度分布比例
  - `#blackhole` CSS 橢圓暗帶 + feTurbulence 雜訊
- **可動部分**：無。**完全不動**
- **應用規則**：元素 4 真 z-軸景深**禁止於首頁使用**（首頁背景已由 Three.js 提供深度）

### 保護區 C｜太空人佔位空間
- **保護內容**：Hero 區塊內預留給太空人的矩形區域（約佔右半部）
- **可動部分**：太空人圖片本身（可換 3D 模型）、太空人動畫（float 等）、圖片尺寸
- **應用規則**：元素 2 格線破格、元素 3 劇場式負空間、元素 5 精密測量標註使用時，必須避開此區域

## 3. 字型系統（沿用 v1.0，已落地於 tokens.css）

### 3.1 字型分派

| 變數 | 字型 | 用途 | 不得用於 |
|------|------|------|----------|
| `--f-sans` | Noto Sans TC | 全站中文內文、多數 UI 文字 | — |

### 3.2 Fraunces opsz 分級使用

| 情境 | 字級 | `opsz` | `wght` | `SOFT` | 字腔 |

| Title | 28–40px | 72 | 400–500 | 30 | 中等張力 |
| Subtitle | 18–24px | 36 | 400 | 50 | 字腔放鬆 |
| Inline | 14–18px | 14 | 400 | 50 | 貼近正文 |

※ 元素 1（Variable Font 多軸滾動）會使上述數值隨捲動連續變化，上表是靜態起點值。

### 元素 1｜Variable Font 多軸滾動

| 欄位 | 內容 |
|------|------|
| **一句話** | Fraunces 的 opsz / wght / SOFT 三軸跟著捲動連續變化，字型內部在動，不是位置在動 |
| **抽象特性** | 字型「內部參數」隨使用者行為實時變形。字本身是活的，不是被動的貼紙 |
| **技術實作** | ① 原生：CSS `scroll-timeline` + `@keyframes` 驅動 `font-variation-settings`（2024+ 支援）<br>② Fallback：ScrollTrigger + GSAP 驅動 `font-variation-settings`<br>③ 軸動範圍例：Hero 標題 `scroll 0%: opsz 144, wght 300, SOFT 20` → `scroll 100%: opsz 14, wght 600, SOFT 60`<br>④ 至少 2 軸同動，單軸變化太平淡 |
| **使用原則** | ① 僅作用於 Fraunces（`var(--f-serif)`），中文不適用<br>② 每頁至多 2 處軸動元素<br>③ 首頁作用於 Hero 標題 + Manifesto 英文大字 |
| **克制邊界** | ❌ 軸動速度超過 0.3 軸變化 / 100vh 捲動（會暈）<br>❌ 與元素 2 格線破格同一元素同時使用<br>❌ Hover 觸發軸動（scroll-only，避免無關動作觸發） |
| **skill 根據** | frontend-design：「distinctive, characterful typography」+ animation-designer：scroll-linked animation |
| **DNA 對應** | 🔥 創新（2024+ 技術）+ 大膽（字型內部在動） |

---

### 元素 2｜格線破格（Grid Break）

| 欄位 | 內容 |
|------|------|
| **一句話** | 元素刻意突破 container 的預期邊界，進入原本屬於 margin / gutter 的空間 |
| **抽象特性** | 內容不服從 grid 的預期，但破格本身是有秩序的（破得有系統，不是亂） |
| **技術實作** | ① 三級破格幅度 token：<br>　小：`margin: 0 -40px`（延伸到 container padding 外）<br>　中：`transform: translateX(-10vw)`<br>　大：`transform: translateX(-20vw)`（穿透至視窗邊緣）<br>② 每頁預設最多 2 處破格<br>③ Mobile（≤900px）時破格幅度減半或完全取消<br>④ 破格元素可配合稜鏡邊緣（元素 8）標示「這是故意的」 |
| **使用原則** | ① 用於：Bento FEATURED 卡、Manifesto 英文大字、最終 CTA 區塊、品牌故事章節標題<br>② 首頁：可用於 Hero 標題，但**必須避開保護區 C（太空人區域）**<br>③ 一頁 2 處為上限 |
| **克制邊界** | ❌ 保護區 A / B / C 全部豁免<br>❌ 3 處以上破格（視覺混亂）<br>❌ Mobile 單欄時破出視窗（產生水平捲動 bug）<br>❌ 與元素 1 Variable Font 軸動同一元素使用 |
| **skill 根據** | frontend-design：「grid-breaking elements, unexpected layouts, asymmetry」明文要求 |
| **DNA 對應** | 🔥 跳脫框架（字面意義）+ 大膽 |

### 元素 3｜劇場式負空間（Negative Space Drama）

| 欄位 | 內容 |
|------|------|
| **一句話** | 單屏刻意 70–80% 留白，內容集中佔小區域，留白本身是主角 |
| **抽象特性** | 違反「塞滿螢幕才值回票價」的直覺。留白承擔「呼吸、沈澱、聚焦」的敘事功能 |
| **技術實作** | ① 區塊高度 ≥ 100vh<br>② 內容 grid-column 限制在視窗 20–30% 範圍，位置偏置（靠左 20% / 靠右 20% / 正中）<br>③ 留白裡放**一個**極細節引導（元素 5 精密標註的單線段、元素 6 讀數條的片段、或單一座標文字），不完全空白<br>④ Mobile 時留白幅度減為 40–50%，避免「內容擠在頂端」感 |
| **使用原則** | ① 每頁至多 1 處<br>② 通常放在區塊之間的過渡位置或關鍵宣言區塊前<br>③ 首頁若採用：放在 Manifesto 區塊進場前 |
| **克制邊界** | ❌ 連續兩區塊都負空間<br>❌ 完全空白無引導（看起來像載入失敗）<br>❌ 與元素 4 z-軸景深同區塊使用（意圖衝突，一個要空一個要深）<br>❌ Mobile 保持 70% 留白 |
| **skill 根據** | frontend-design：「generous negative space OR controlled density」、「dominant negative space」 |
| **DNA 對應** | 🔥 大膽（敢留就是大膽）+ 跳脫框架 |

### 元素 4｜真 z-軸景深層（Layered Depth Planes）

| 欄位 | 內容 |
|------|------|
| **一句話** | 畫面分成背景 / 中景 / 前景三層，每層獨立捲動速度 + 獨立模糊 + 獨立透明度 |
| **抽象特性** | 不是視差（只改位置），是**位置 + 模糊 + 透明度同時分層**。博物館展櫃的立體縱深感 |
| **技術實作** | ① 背景層（z-index 0）：scroll 0.3x speed，`filter: blur(3px)`，`opacity: 0.6`<br>② 中景層（z-index 5）：scroll 1x，無模糊，`opacity: 1`<br>③ 前景層（z-index 10）：scroll 1.2x，`filter: blur(0.5px)`，`opacity: 0.9`<br>④ 滑鼠位置做輕微位移（±5px），增強立體感<br>⑤ 使用 `will-change: transform` 與 `transform: translate3d()` 保持 GPU 合成 |
| **使用原則** | ① **首頁禁用**（Three.js 黑洞已提供深度，疊加會打架）<br>② 其他 10 頁可用<br>③ 每頁 1–2 個關鍵敘事區塊使用 |
| **克制邊界** | ❌ 首頁（保護區 B）<br>❌ 全頁都用（變成主題樂園）<br>❌ 前景模糊超過 1px（看不清）<br>❌ 背景層模糊超過 5px（不如用靜態圖）<br>❌ 與元素 3 劇場式負空間同區塊使用 |
| **skill 根據** | animation-designer：parallax 進階版 + frontend-design：「layered transparencies, dramatic depth」 |
| **DNA 對應** | 🔥 質感（博物館展櫃的立體感）+ 創新（真正的三層而非兩層視差） |

### 元素 5｜精密測量標註（Technical Drawing Annotations）

| 欄位 | 內容 |
|------|------|
| **一句話** | 極細線 + 等寬字標記，圍繞關鍵內容，像工程圖 / 觀測儀器解說 |
| **抽象特性** | 不是裝飾，是「精度聲明」。讓內容看起來像被精密儀器測量過 |
| **技術實作** | ① SVG 做：<br>　尺寸線（兩端短横線 + 中間標註值）<br>　角度弧 + 標註（如 `∠ 15°`）<br>　半徑線 + 標註（如 `Ø 64`）<br>　公差標記（如 `±0.02`）<br>② 線寬 0.5–1px，顏色 `rgba(232,240,255,0.35)`<br>③ 等寬字 JetBrains Mono 10–11px，`letter-spacing: 0.1em`<br>④ 標註與被標註內容間距固定 24px（1 grid unit）<br>⑤ 進場時 SVG 線條以 `stroke-dashoffset` 由小到大畫出 |
| **使用原則** | ① 僅用於「宣稱精度」的內容：服務規格、技術參數、數據對比、時間軸年份<br>② 每頁 1–3 處<br>③ 首頁：Bento 服務卡可選擇性使用一張；品牌故事「2020 / 2024」年份可加時間軸標註 |

| **skill 根據** | frontend-design：「unexpected decoration, precision detail」+ 觀測站主題直接回應 |
| **DNA 對應** | 🔥 跳脫框架（UI 鮮少這樣用）+ 質感（精密儀器質感） |

### 元素 7｜潮汐式進場（Tidal Staggered Reveal）

| 欄位 | 內容 |
|------|------|
| **一句話** | 滾入時元素非等距 stagger，而是依視覺權重排序：重元素先到位，輕元素後到 |
| **抽象特性** | 一般 stagger 是「均勻流瀉」；潮汐式是「潮水湧入後細節浮現」。節奏有輕重而非等速 |
| **技術實作** | ① 每個可進場元素打上 `data-weight` 屬性（1–5，5 為視覺最重）<br>② GSAP timeline 依 weight 排序：weight 5 先，weight 1 最後<br>③ 進場時長依 weight 變化：<br>　weight 5：duration 0.8s，ease `expo.out`<br>　weight 3：duration 0.6s，ease `power4.out`<br>　weight 1：duration 0.4s，ease `power2.out`<br>④ stagger 間距依相鄰 weight 差：<br>　重元素間 stagger 150ms<br>　輕元素間 stagger 60ms<br>⑤ 觸發：IntersectionObserver 當區塊進入視窗 20% 時啟動 |
| **使用原則** | ① 每頁 scroll-into-view 的主要敘事區塊使用（Bento、Services、Timeline）<br>② 列表類區塊特別適合（服務方案、時間軸節點）<br>③ 搭配元素 7 描邊或 resize 進場時，進場事件只跑一次 |
| **克制邊界** | ❌ 同區塊超過 8 個元素進場（stagger 變太長）<br>❌ 兩區塊同時進場（破壞層次）<br>❌ Hero 區塊（不是 scroll-in 元素，由 GSAP 獨立處理）<br>❌ 與元素 1 Variable Font 軸動同時間發生 |
| **skill 根據** | animation-designer：staggered reveal 進階 + ui-ux-pro-max：「motion conveys meaning（重元素 = 主體，輕元素 = 細節）」 |
| **DNA 對應** | 🔥 創新（非線性 stagger 少見）+ 質感（節奏的輕重處理） |

### 元素 8｜稜鏡邊緣（Spectral Edge）

| 欄位 | 內容 |
|------|------|
| **一句話** | 容器邊緣 1–2px 稜鏡彩細線，像光學鏡片邊緣的色散，飽和度極低 |

| **技術實作** | ① 方式 A（border-image）：<br>```css<br>border-image: linear-gradient(90deg,<br>  rgba(0,200,255,0.3) 0%,<br>  rgba(232,240,255,0.2) 33%,<br>  rgba(245,166,35,0.2) 66%,<br>  rgba(0,200,255,0.3) 100%) 1;<br>```<br>② 方式 B（::before 偽元素 + position absolute）：`inset: -1px`，背景為上述漸層，`pointer-events: none`<br>③ 線寬 1–2px<br>④ 飽和度（漸層各段 alpha）≤ 0.3<br>⑤ 可選：hover 時整條光線「流動」一次（`background-position` 從 0% 到 100%，duration 1.6s） |

| **DNA 對應** | 🔥 質感（細節處理）|

## 8. 元素組合原則

### 8.1 一頁元素數量上限

**至多 3 個元素同時作用**（包含簽名元素）。超過則視覺過載。

### 8.2 不相容組合黑名單

下列組合**不得同一元素 / 同一區塊 / 同時機使用**：

| 組合 | 衝突原因 |
|------|---------|
| 元素 1（Variable Font 軸動） + 元素 2（格線破格）**用在同一元素** | 雙重動態負擔，看不懂哪個在動 |
| 元素 3（劇場式負空間） + 元素 4（z-軸景深）**用在同一區塊** | 意圖衝突：一個刻意空、一個刻意深 |
| 元素 1（字軸動） + 元素 7（潮汐進場）**同時進行** | 兩組動態分散注意力 |
| 元素 4（z-軸景深）+ 首頁任何區塊 | 首頁背景已被 Three.js 佔用（保護區 B） |

### 8.3 簽名元素原則

每頁**必有一個簽名元素**（該頁代表作，以最完整形式呈現）。其他被選用的元素為它讓位（降級使用，飽和度 / 強度 / 頻率均減半）。

## 10. 克制總則（什麼時候什麼都不做）

| 情境 | 不做什麼 |
|------|---------|
| 內文段落 | 不加任何裝飾元素。純文字 + 基線對齊 + 行高 1.5 |
| 導覽列與頁尾 | 不加元素 1–8 任何一個。保持系統級冷靜 |
| 區塊之間的大留白 | 什麼都不放。留白本身就是元素 |
| 第二次出現的元素 | 降級使用（飽和度減半、軸動幅度減半、stagger 距離減半） |
| 當頁面已有 3 個元素 | 不再加第四個，即使看起來「還能放」 |
| 保護區 A / B / C | 按保護清單規則，不得被擠占 |
