## 一、整體設計語言

### 核心概念：「深空漂流」

官網本身就是品牌 DNA 的具現化——非常規、跳躍、讓人看了為之一亮。
視覺主軸取「太空」隱喻：宇宙是無邊界的探索場域，太空人是敢踏出去的人，而創巢就是那個幫你離開地面的團隊。

### 配色系統（保留員工原始設計）

| 角色 | 色碼 | 用途 |
|------|------|------|
| 品牌藍 | `#1736F5` | 主視覺、互動元素、卡片邊框 |
| 深海軍藍 | `#0b1a7a` | 漸層底層、區塊背景 |
| 宇宙黑 | `#050d2e` | 全站底色 |
| 亮黃 | `#FFC709` | 強調色、CTA、關鍵字highlight |
| 純白 | `#FFFFFF` | 主文字 |
| 霧白 | `rgba(255,255,255,0.6)` | 次要文字 |

### 字型系統

| 用途 | 字型 | 字重 |
|------|------|------|
| 中文標題 | Noto Sans TC | 900 |
| 中文內文 | Noto Sans TC | 400／700 |
| 英文顯示標題 | Exo 2 | 700／900 |
| 英文標籤／TAG | Exo 2 | 400 |

### 全站氛圍技術清單

- **星空背景**：Three.js 粒子星場，固定在畫面後層，全站共用
- **玻璃擬態卡片**：`backdrop-filter: blur` + 半透明藍色邊框
- **滾動觸發動畫**：GSAP ScrollTrigger，每區塊進場有獨立動畫
- **懸浮效果**：卡片 hover 上浮 + 邊框轉黃色
- **頁面載入**：GSAP 入場序列（品牌 tag → 標題 → 副標 → CTA，錯開 0.2s）

### 導覽列設計

```
[ 創巢數位 NestX ]  關於我們  服務項目  最新消息  [ 聯絡我們 ]
```
- 浮動膠囊形（floating pill），固定在頂部
- 預設半透明 `rgba(5,13,46,0.7)` + 毛玻璃模糊
- 滾動超過 100px → 加深背景
- 手機版：底部 Dock（延續現有設計，視覺升級）
