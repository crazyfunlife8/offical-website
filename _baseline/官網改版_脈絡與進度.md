## 任務背景與脈絡

現行官網（nestxmedia.com）為員工與前合夥人製作的初版，創辦人全程未參與。2026-04-15 起由創辦人主導整體升級改版，以品牌DNA為起點重新定義，不被現有框架限制。

### 品牌 DNA（改版核心依據）

- **精神起源**：「不正常人類軟體開發」這個名字背後，是創辦人真實的世界觀——這個世界太亂，需要以非常規的跳躍思維來改變
- **演進路徑**：不正常人類軟體開發（2020）→ 創巢數位 Nest Digital（2024），從純軟體開發擴展到行銷一條龍
- **核心能力**：軟體開發 × 品牌行銷 × AI應用 × 自動化，能做到從開發到企業AI整合協作輔導的完整鏈

### 視覺設計語言定案（2026-04-18）

**總定位**：天文觀測站的質感（博物館 / 高級光學儀器），非科幻片炫技。對應品牌 DNA「沉穩的異類，不是吵鬧的怪咖」。

**一句話傳達的感受**：「你進來的不是一個網站，是一台被精密校準的光學儀器，對準了深空。它不催促你，但你知道它看得比你遠。」

**核心三元素（整體語彙，不可拆）**

| # | 元素 | 用意 |
|---|------|------|
| 1 | 光與影的雕刻 | 關鍵文字 `text-shadow` 內凹 + 微浮雕雙層，讓字像被光雕出而非貼上（「質感」的根） |
| 2 | ~~軌道環結構~~ | ~~Hero 太空人外圍 SVG 細軌道環（≥60s/圈），建立引力 / 秩序 / 宇宙尺度語言~~ **2026-04-18 實測後停用：太空人周圍已有 PNG 本身光暈，疊加軌道環視覺擁擠，使用者回饋多餘；JS 呼叫已註解，CSS 與函式保留** |
| 3 | 星座連線 | Bento 六張服務卡之間極細線相連成星座，同時傳達「個別獨立」+「整合串聯」，呼應「軟體 × 行銷 × AI × 自動化」整合敘事 |

**節奏點綴元素（微量，不可濫用）**

| 元素 | 使用規則 |
|------|---------|
| 體積光 God Rays | 頂部斜射一道（+15° 與黑洞同傾斜），靜態或極緩漂移 |
| 金屬光澤掃光 | 僅限 Hero「UNCONVENTIONAL」與最終 CTA 按鈕；偶發不 loop |
| SVG 描邊動畫 | 服務卡進入視野時邊框被畫出（stroke-dashoffset），1.2s 後靜止 |
| 稜鏡折射光斑 | 品牌故事區塊極緩橫越一次 |

**細節裝飾**

| 元素 | 使用規則 |
|------|---------|
| 座標文字 | 頁面四角等寬字 LAT/LON/Z，靜態 |
| 磁性按鈕 | 僅限主 CTA 一顆，游標靠近偏移 6–8px |
| 內凹陰影 | CTA 按鈕內緣與關鍵文字 |

**體驗敘事節奏**

| 階段 | 感受 | 使用元素 |
|------|------|---------|
| 0–2 秒 | 深淵美 | 黑洞星場 + God Rays |
| 2–5 秒 | 非一般公司 | UNCONVENTIONAL 金屬掃光偶發 |
| 滾入故事 | 有引導感 | 太空人軌道環旋轉 |
| 看服務 | 每個服務像星體 | 星座連線 + SVG 描邊進場 |
| 品牌故事 | 歷史有重量 | 稜鏡折射光斑橫越 |
| CTA | 被吸引，不被催促 | 磁性按鈕 + 內凹陰影 |
| 全程 | 每個細節都被設計過 | 座標文字四角 |

**刻意排除（為何不要）**

| 元素 | 排除原因 |
|------|---------|
| 掃描線 / Glitch / 色差 | 太賽博龐克，廉價，與「質感」衝突 |
| HUD 瞄準框 / 終端機啟動序列 | 太遊戲 UI，失去冷靜 |
| 全像箔彩虹光 | 太 Gen-Z 消費品感，與品牌深度不符 |
| 六角蜂巢 / 電路板紋 | 太陽剛工業，破壞深空沉靜 |
| 文字解碼動畫全站用 | 用一次有驚喜，滿場即 low |
| 像素崩解 | 太遊戲，俗 |

**備註**：此為初版決策，實作後將根據實際畫面進行調整。
